PREMIUM KATALOG PRODUK TEMPLATE

Konsep:
Template katalog modern/editorial yang sengaja dibuat berbeda dari company profile biasa.

File:
- index.html
- style.css
- script.js

Fitur:
- Hero editorial
- Product grid 8 produk
- Search
- Filter kategori
- Product detail modal
- Simpan produk / wishlist sederhana
- Drawer "Saved products"
- Order melalui WhatsApp
- Responsive mobile/tablet/desktop
- Mobile navigation
- Ticker/promo bar
- Collection editorial section

Kustomisasi:
1. Ubah nama toko di index.html.
2. Ubah nomor WhatsApp 6281234567890 pada index.html dan script.js.
3. Ubah data produk pada array "products" di script.js.
4. Untuk foto asli, ganti .product-img/.hero-photo/.editorial-image dengan <img>.
5. Upload ke GitHub Pages/hosting.
